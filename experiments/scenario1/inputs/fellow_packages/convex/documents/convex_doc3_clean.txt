4 Step-size selection and backtracking
If L is unknown, backtracking line search starts with a trial step and shrinks it until a
sufficient-decrease inequality holds, for example
f(x − α∇f(x)) ≤ f(x) − cα∥∇f(x)∥2
for a chosen c ∈ (0,1).
Common mistake: A decreasing objective is not the only goal
A tiny step can decrease the objective but make progress painfully slow. A large
step can oscillate or diverge. Step-size diagnostics should examine both descent
and speed.
Listing 1: Gradient descent with backtracking
def gradient_descent(f, grad, x0, tol=1e-6, max_iter=10_000):
x = x0.copy()
history = []
for k in range(max_iter):
g = grad(x)

history.append((k, f(x), float((g @ g) ** 0.5)))
if (g @ g) ** 0.5 <= tol:
break
step = 1.0
while f(x - step * g) > f(x) - 1e-4 * step * (g @ g):
step *= 0.5
x = x - step * g
return x, history

10 Scaling and preconditioning
Poor scaling can make an easy problem look algorithmically hard. Useful interventions
include:
• normalize columns of a data matrix;
• rescale variables so typical magnitudes are comparable;
• use diagonal preconditioning for quadratics;
• reformulate constraints to avoid extremely large and small coefficients in the same row;
• inspect solver warnings before increasing iteration limits.

Listing 2: Proximal gradient for LASSO
import numpy as np
def soft_threshold(z, tau):
return np.sign(z) * np.maximum(np.abs(z) - tau, 0.0)
def lasso_prox_grad(A, b, lam, x0, max_iter=2000, tol=1e-6):
x = x0.copy()
L = np.linalg.norm(A, 2) ** 2
step = 1.0 / L
history = []
for k in range(max_iter):
grad = A.T @ (A @ x - b)
x_new = soft_threshold(x - step * grad, step * lam)
obj = 0.5 * np.linalg.norm(A @ x_new - b) ** 2 + lam * np.linalg.norm(x_new,
1)
history.append(obj)
if np.linalg.norm(x_new - x) <= tol * max(1.0, np.linalg.norm(x)):
x = x_new
break
x = x_new
return x, history
